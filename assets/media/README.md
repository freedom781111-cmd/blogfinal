# Photo upload map

Use these folders for site images. Keep the exact file names shown here so the static site can display them automatically on GitHub Pages.

Recommended format: `.jpg`, sRGB, optimized for web, under 700 KB when possible.

| Section | Folder | File name | Recommended size | Where it appears |
| --- | --- | --- | --- | --- |
| Home hero | `assets/media/hero/` | `hero-main.jpg` | 2400 x 1600 px | First screen background |
| Selected work | `assets/media/work/` | See `assets/media/work/README.md` | 1800 x 1200 px | Work cards |
| Projects | `assets/media/projects/` | See `assets/media/projects/README.md` | 1800 x 1200 px | Project rows |
| Writing | `assets/media/writing/` | `<post-slug>.jpg` | 1600 x 1000 px | Writing cards and reader |
| About | `assets/media/about/` | `bio-silvio-campos.jpg` | 1200 x 1500 px or square crop | Bio portrait |

For writing images, match the blog post slug. Example: `no-quieren-verdad-quieren-statement.jpg`.
